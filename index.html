مميزات البرنامجWhat's inside

آلاف القطع الجاهزة: Arduino وحساسات ومقاومات وLEDs ودوائر متكاملة.Thousands of ready parts: Arduino boards, sensors, resistors, LEDs and ICs.

شاشات مترابطةLinked views

أي تعديل في الـ Breadboard بيظهر تلقائيًا في الـ Schematic والـ PCB.Edit in Breadboard and it shows up in Schematic and PCB automatically.

تصدير للتصنيعExport for fabrication

صدّر ملفات Gerber جاهزة لإرسالها لمصانع لوحات الـ PCB.Export Gerber files ready to send to a PCB manufacturer.

محرر كودCode editor

اكتب وعدّل كود Arduino جنب الدائرة. الرفع الأسهل من Arduino IDE.Write Arduino code next to your circuit. Uploading is easiest from Arduino IDE.

أمثلة جاهزةBuilt-in examples

افتح مشاريع جاهزة من قائمة Examples وتعلّم منها خطوة خطوة.Open ready projects from the Examples menu and learn from them step by step.

محرر القطعParts editor

اعمل قطعة جديدة بشكلها ورجولها لو مش موجودة في المكتبة.Create a custom part with its own look and pins if the library lacks it.

مساعد الكود بالذكاء الاصطناعيAI code helper

اوصف دائرتك واختار اللوح، وهيطلعلك كود جاهز مع جدول التوصيلات والمكتبات.Describe your circuit and pick a board to get ready code, a wiring table and the libraries you need.


      
الذكاء الاصطناعي ممكن يغلط: راجع التوصيلات وجهد القطع قبل ما توصّل الكهربا.AI can make mistakes: check the wiring and part voltages before powering anything.

أسئلة شائعةFAQ

    

      
هل أحتاج أثبّت البرنامج؟Do I need to install it?
لا. النسخة محمولة: فك الضغط وشغّل Fritzing.exe مباشرة.No. It is portable: extract and run Fritzing.exe directly.

      
ليه SmartScreen بيحذّرني؟Why does SmartScreen warn me?
لأن الملف غير موقّع رقميًا ومش معروف لدى ويندوز. اختار More info ثم Run anyway.Because the file is not digitally signed and not yet known to Windows. Choose More info, then Run anyway.

      
أقدر أشغّله من فلاشة؟Can I run it from a USB drive?
غالبًا أيوه لأنها نسخة محمولة، بشرط تنسخ المجلد كامل. لو حسيت ببطء انسخه على الهارد.Most likely yes since it is portable, as long as you copy the whole folder. If it feels slow, copy it to your hard drive.

      
البرنامج مش بيفتح، أعمل إيه؟It will not open. What now?
تأكد إنك فكيت الضغط بالكامل (مش من جوه الـ ZIP) وإن ويندوزك 64-bit.Make sure you fully extracted the ZIP (not run from inside it) and that your Windows is 64-bit.
